# 金(XAUUSD)ナンピンEA

MT5 用のナンピンEAと、同じロジックを再現する Python バックテスター、パラメータ探索の結果をまとめたディレクトリ。

**探索結果の詳細は [results/results.md](results/results.md) を参照。**

## 結論 (要約)

* 元手500万円・最大DD20%以内・黒字を条件に、28,800 通りを前半(2026/4/20〜7/6)で最適化し、後半(7/6〜9/26)で検証した。
* 前半の成績だけで選んだ上位設定は、後半ではほとんど通用しなかった (上位10件中、後半も合格は1件)。前半が下落相場だったため「売りのみ・大ロット」が上位になり、後半の上昇で崩れた。
* 前半・後半の両方で合格し、さらに「開始日を1週ずつずらした15期間」「パラメータを1段階ずらした近傍」「スプレッド・スワップ悪化」でも崩れにくい設定に絞ると、5か月で +10〜30% 程度。
* 前回の「生存」設定 (買いのみ・幅$5・最大20本) は、今回のデータでは6月の急落でロスカットされた。
* 安定させる効果が最も大きかったのは **H4 SMA100 のトレンドフィルタ** (新規エントリーを上昇中は買い、下降中は売りに限定)。

| 候補 | 方向 | 初期ロット | ナンピン幅 | 最大本数 | 利確 | 口座損切り | 全期間 利益 | 全期間 最大DD |
|---|---|---|---|---|---|---|---|---|
| A | 両方 | 0.10 | $100 | 20 | $20幅相当 (¥30,000) | 5% | +81万円 | 18.1% |
| B | 売りのみ | 0.01 | $10 | 8 | $40幅相当 (¥6,000) | 15% | +146万円 | 10.9% |
| C | 買いのみ | 0.03 | $50 | 15 | $20幅相当 (¥9,000) | なし | +71万円 | 15.5% |

すべて H4 SMA100 フィルタ、倍率 1.2。A は相場の向きに賭けない設定、B は成績が最も安定しているが下落相場の恩恵を受けている点に注意。

> **重要:** 無料で取得できた1分足は 2026/3/26〜9/25 の約6か月のみで、候補はすべてこの期間のデータで選んでいる。
> 本番口座で使う前に、MT5 ストラテジーテスターで長期間 (数年) 検証し、デモ口座で数週間フォワードテストすること。

## EA (GoldNanpinEA.mq5)

### 動作

1. 買い・売りそれぞれのバスケットが空なら、トレンドフィルタが許可した方向に初期ロットでエントリー。
2. 直近エントリー価格から「ナンピン幅」だけ逆行したら、`初期ロット × 倍率^本数` のロットで追加 (最大本数まで)。
3. バスケットの合計損益 (スワップ込み) が利確目標に達したら、そのバスケットを一括決済。
4. EA のポジションの含み損が残高の「口座損切り%」に達したら全決済し、「新規停止時間」の間は新規エントリーしない。
5. トレンドフィルタは新規エントリーだけに効く (ナンピン追加は止めない)。確定済みの上位足終値が SMA より上なら買いのみ、下なら売りのみ許可。

### 入力パラメータ

| パラメータ | 既定値 (候補A) | 説明 |
|---|---|---|
| InpDirection | 両方 | 買いのみ / 売りのみ / 両方 |
| InpInitLot | 0.10 | 初期ロット |
| InpMultiplier | 1.2 | ナンピンごとのロット倍率 |
| InpGridStep | 100.0 | ナンピン幅 (価格。金なら USD) |
| InpMaxPositions | 20 | 片方向あたりの最大本数 |
| InpTPMove | 20.0 | 利確目標。初期ロットがこの価格幅だけ有利に動いた時の利益額 (口座通貨) で一括決済 |
| InpAccountStopPct | 5.0 | 口座全体の損切り (残高比 %)。0 で無効 |
| InpCooldownMin | 1440 | 損切り後に新規エントリーを止める時間 (分) |
| InpMaxSpreadPoints | 0 | これより広いスプレッドでは新規・ナンピンしない (0 = 制限なし) |
| InpFilterTF / InpFilterMA | H4 / 100 | トレンドフィルタの時間足と SMA 期間。MA=0 でフィルタなし |
| InpMagic | 20261014 | マジックナンバー |

候補B は `InpDirection=売りのみ, InpInitLot=0.01, InpGridStep=10, InpMaxPositions=8, InpTPMove=40, InpAccountStopPct=15`。
候補C は `InpDirection=買いのみ, InpInitLot=0.03, InpGridStep=50, InpMaxPositions=15, InpTPMove=20, InpAccountStopPct=0`。

### 導入手順

1. `mql5/GoldNanpinEA.mq5` を MT5 の `データフォルダ/MQL5/Experts/` にコピーし、MetaEditor でコンパイル (F7)。
2. XAUUSD のチャートに EA をドラッグし、パラメータを設定。「アルゴリズム取引」を有効にする。
3. **ヘッジ口座専用** (両建てできる口座)。ネッティング口座では起動時にエラーで停止する。
4. 銘柄名が `GOLD` や `XAUUSD.m` などのブローカーでも、その銘柄のチャートに付ければ動く。1 lot = 100 oz を前提に検証しているので、契約サイズが違うブローカーではロットを換算すること。

## Python バックテスター

```bash
cd fx/ea
pip install -r requirements.txt
cd backtest
python optimize.py   # 28,800 通りの探索 (4コアで約4分)
python report.py     # 候補の絞り込みと results.md / equity.png の作成 (約1分)
cd ../tests && pytest -q
```

### 前提 (nanpin_bt.py の `Market`)

| 項目 | 値 |
|---|---|
| 口座 | 500万円、USDJPY 150 固定で円換算 |
| 契約サイズ | 1 lot = 100 oz |
| スプレッド | $0.30 (コスト悪化テストでは $0.50) |
| スワップ | 1lot・1日あたり 買い -$50 / 売り -$10、21:00 UTC に付与、水曜3倍 (悪化テストでは -$80 / -$30) |
| レバレッジ / ロスカット | 100倍 / 証拠金維持率 50% |
| 1分足内の値動き | 陽線は 始値→安値→高値→終値、陰線は 始値→高値→安値→終値。足と足の間の価格差はギャップとして始値で約定 |
| 最大DD | 有効証拠金のピークからの下落率 (足の中の最安値時点で評価) |

ブローカーのスワップ・スプレッドは実際の値に合わせて `Market` を変更すること。

### 長期データでの検証

MT5 に長期の1分足がある場合は `mql5/ExportM1.mq5` を XAUUSD チャートで実行すると `MQL5/Files/XAUUSD_1m.csv` が作られる。
`optimize.py` の `WARMUP_END / SPLIT / END` を期間に合わせて書き換え、`--data` にその CSV を渡せば同じ探索ができる。
