# ナンピンEA:ユーロドル・ポンドドルでの設定探索

金(XAUUSD)向けナンピンEAと同じロジックを EURUSD と GBPUSD に当て、
**前半期間で設定を選び、後半期間でそのまま検証**しました。
各通貨 17,280 通りを総当たりしています。

## 結論

- **金と同じ選び方(前半でDD20%以内・利益最大)は、両通貨とも後半で不合格でした。**
  EURUSD は後半も黒字(+106万円)でしたがDDが28%に膨らみ、GBPUSD は後半 −236万円・DD55%でした。
  前半で最も儲かった設定は、前半の相場に合わせすぎています。
- **前半DDが5%以内の設定に絞って選ぶと、両通貨とも後半で合格しました**(EURUSD 後半 +20万円・DD9.1%、GBPUSD 後半 +60万円・DD10.2%)。
  ただし利回りは年 0.8〜2.6% と小さく、GBPUSD は15分足で再計算すると +7万円・DD15.4% まで悪化します。
  また、この「5%に絞る」ルールは後半の結果を見てから考えたので、後半は完全な未知データとは言えません。
  そこで 2022/03〜2026/10 の日足でも確かめると、GBPUSD は +23万円、EURUSD は −18万円でした。
- 採用された設定は**すべて「売りのみ」**でした。2012〜2022年はドル高(EURUSD 1.30→1.09、GBPUSD 1.59→1.32)だったためで、
  ドル安が長く続く局面では同じ結果にならない可能性があります。
- **「最大DD20%以内で、しっかり黒字」をドルストレートで両立する設定は見つかっていません。**
  大きく稼ぐ設定はDDか破綻のリスクが大きく、安全な設定は年数%しか稼ぎません。

## 通貨ごとの採用設定

元手500万円、国内口座想定(レバレッジ25倍・証拠金維持率100%でロスカット)、スワップは1ロット1日 −5 USD、1ドル150円で換算しています。

| | EURUSD A | EURUSD B | GBPUSD A | GBPUSD B |
|---|---|---|---|---|
| 選び方 | 前半DD20%以内で利益最大 | 前半DD5%以内で利益最大 | 前半DD20%以内で利益最大 | 前半DD5%以内で利益最大 |
| 方向 | 売りのみ | 売りのみ | 売りのみ | 売りのみ |
| 初期ロット | 0.01 | 0.01 | 0.01 | 0.01 |
| 倍率 | 1.2 | 1.2 | 1.5 | 1.2 |
| ナンピン幅 | 20 pips | 50 pips | 20 pips | 80 pips |
| 最大本数 | 20 | 10 | 10 | 15 |
| 利確幅(平均建値から) | 40 pips | 40 pips | 20 pips | 40 pips |
| 口座損切り | 20% | 10% | 20% | 10% |
| 200MAフィルタ | なし | なし | あり | なし |
| 前半 利益 / 最大DD | +372万円 / 19.3% | +59万円 / 3.5% | +411万円 / 17.1% | +66万円 / 3.7% |
| **後半 利益 / 最大DD** | **+106万円 / 27.9%** | **+20万円 / 9.1%** | **−236万円 / 55.1%** | **+60万円 / 10.2%** |
| 後半の判定 | 不合格(DD超過) | 合格 | 不合格(赤字・DD超過) | 合格 |
| 後半を15分足で再計算 | +114万円 / 28.2% | +19万円 / 9.1% | −216万円 / 54.4% | +7万円 / 15.4% |
| 2022/03〜2026/10 日足(簡易) | +40万円 / 8.8% | −18万円 / 9.8% | +89万円 / 14.2% | +23万円 / 8.6% |

- 前半 = 2012/11/16〜2017/07/14、後半 = 2017/07/14〜2022/03/04(1時間足)。
- 「合格」は破綻なし・最大DD20%以内・黒字の3つを満たすことです。
- 「2022/03〜2026/10 日足」は日足終値しかないデータでの確認です。日中の値動きを無視するので、DDは実際より小さく出ます。
- 海外口座条件(レバレッジ500倍・維持率20%)でも、採用設定のDDは同じでした。証拠金不足になる前に口座損切りが効くためです。

## 破綻した設定の傾向

17,280 通りのうち、ロスカット(破綻)したのは次のとおりです。

| | 前半 | 後半 |
|---|---|---|
| EURUSD | 5,155 通り(30%) | 3,270 通り(19%) |
| GBPUSD | 6,794 通り(39%) | 5,175 通り(30%) |

パラメータごとの破綻率(後半、EURUSD / GBPUSD)は次のとおりです。全体は [results/](results/) の `*_tendency.csv` にあります。

| パラメータ | 破綻しやすい | 破綻しにくい |
|---|---|---|
| 初期ロット | 0.10:33% / 52% | 0.01:8% / 14% |
| 倍率 | 1.5:40% / 56% | 1.0:1% / 6% |
| ナンピン幅 | 10 pips:35% / 47% | 80 pips:5% / 12% |
| 最大本数 | 20本:31% / 45% | 5本:1% / 6% |
| 口座損切り | なし:29% / 43% | 10%:11% / 20% |
| 方向 | 両建て:20% / 35% | 売りのみ:17% / 26% |

- 破綻の大半は「**ロットが大きい × 倍率1.5 × 幅が狭い × 本数が多い**」の組み合わせで起きています。
  一方向に 200〜400 pips 動くと、最後の数本のロットが大きく膨らんで証拠金が尽きます。
- 買いのみは前半(ドル高局面)でほぼ全滅しました(合格率 EURUSD 0.4%、GBPUSD 0%)。両建ても、逆行側のバスケットが同じ理由で崩れます。
- 利確幅と200MAフィルタは、破綻率にほとんど影響しませんでした。200MA(1時間足で約8日分)は短すぎて、数か月続くトレンドを避けられません。
- 前半で合格した設定のうち、後半も合格した割合は EURUSD 80%、GBPUSD 23% でした。ポンドは前半の結果があてになりにくい通貨です。

## データ

- 1時間足・15分足 OHLC(2012/11〜2022/03):[ejtraderLabs/historical-data](https://github.com/ejtraderLabs/historical-data)。
  2022年3月で更新が止まっているため、それ以降は使っていません。ライセンス表記がないので、データ本体はコミットしていません。
- 日足終値(〜2026/10):[datasets/exchange-rates](https://github.com/datasets/exchange-rates)(FRED H.10、PDDL)。
- この環境からは Dukascopy・Yahoo などのデータ配信元に接続できませんでした。MT5 からエクスポートした新しいデータがあれば、
  `time,open,high,low,close` の CSV にして `data/EURUSD_H1.csv` を置き換えれば、そのまま回せます。

## バックテストの前提

| 項目 | 値 |
|---|---|
| 元手 | 500万円 |
| 円換算 | 1ドル150円で固定(為替差は無視) |
| 口座 | レバレッジ25倍、証拠金維持率100%でロスカット(=破綻、そこで停止) |
| スプレッド | EURUSD 1.0 pips、GBPUSD 1.5 pips |
| スワップ | 売り買いとも1ロット1日 −5 USD(水曜は3日分)。実際の売りスワップはプラスのことが多いので、売りには不利な仮定 |
| 約定 | 1時間足の中を「陽線は 始→安→高→終、陰線は 始→高→安→終」と動いたとみなし、指値の水準で約定。窓開けは始値で約定 |
| ロット | 初期ロット × 倍率^n を 0.01 単位で四捨五入(MQL の NormalizeDouble と同じ) |
| 証拠金不足 | 余剰証拠金が足りない追加注文は見送り |

## EAのロジック(バックテスターが再現しているもの)

1. ポジションが無ければ、バーの始値で初期ロットを建てる。200MAフィルタを使う場合は、直前バーの終値が200MAより上なら買い、下なら売りだけを新規で建てる。
2. 最後の建値から「ナンピン幅」だけ逆行するたびに、初期ロット × 倍率^n で追加する。最大本数に達したら追加しない。
3. 平均建値から「利確幅」だけ有利になったら、全ポジションを一括決済する(合計利益 = 総ロット × 利確幅)。
4. 口座損切り:有効証拠金が「残高 ×(1 − 損切り%)」を割ったら全決済し、取引は続ける。
5. 両建ては、買いと売りのバスケットを独立に同時に動かす。

## 注意

- 過去10年でうまくいった設定が今後も通用する保証はありません。特に「売りのみ」はドル高の時期に選ばれた設定です。
- 15分足で再計算すると、GBPUSD B の後半成績は大きく悪化しました。ナンピン幅が広く損切りが浅い設定は、バー内の値動きの順序に敏感です。
  実運用の前に、MT5 のストラテジーテスター(全ティック)で必ず確認してください。
